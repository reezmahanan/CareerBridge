# CareerBridge 🌉

CareerBridge is a simple job portal website developed using **HTML, CSS, and JavaScript**. The project allows job seekers to search and apply for jobs, while employers can post job vacancies and manage job listings.

## Live Demo

https://reezmahanan.github.io/CareerBridge/

---

## Project Overview

CareerBridge was created as a learning project to understand how job portal websites work. The application follows a Single Page Application (SPA) approach and provides different features for job seekers, employers, and administrators.

The project is built without using any frameworks, making it easier for beginners to understand the code structure and functionality.

---

## Features

### Job Seeker Features

* Browse available jobs
* Search and filter job listings
* Save jobs for later
* Apply for jobs
* View application history
* Access career advice and resume tips

### Employer Features

* Post new job vacancies
* Search candidate profiles
* Manage company branding
* View recruitment solutions

### Admin Features

* Access platform statistics
* Monitor overall system activities

### General Features

* Responsive design for mobile and desktop devices
* Role-based login system
* Interactive notifications
* Job and company detail popups
* Browser navigation support

## How to Run the Project

### Method 1: Open Directly

Simply open the `index.html` file in your web browser.

### Method 2: Use a Local Server

Using Python:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Limitations

* Login system is for demonstration purposes only
* No real database is connected
* Data is stored in the browser using Local Storage
* File upload functionality is not implemented
* Internet connection is required for external images and icons
